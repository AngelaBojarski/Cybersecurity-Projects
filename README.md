# Cybersecurity-Projects
Collection of current cybersecurity related projects


The following projects have been adapted from Faan Ross's [Youtube Series Python Cybersecuirty for Beginners](https://www.youtube.com/watch?v=UfyF6CvL4Ts&list=PLB7R26sRn2aLhKbDDRtd7wluaX91pqAQD&index=1):

- Firewall Simulator
- DoS Blocker
- Mini Firewall
- Ping Sweeper
- Port Scanner
- OS Fingerprint
- Service Fingerprint


## Firewall Simulator

Purpose: Understand the basics of a firewall and its uses

## DoS Blocker

Purpose: Monitor network traffic and detect potential Denial of Service attacks

## Mini Firewall

Purpose: Combine basic firewall practices to create a simple firewall

## Ping Sweeper

Purpose: Ping IP's and output live addresses

## Port Scanner

Purpose: Build off of ping sweeper and output open ports and use multi-threading

## Service Fingerprint

Purpose: Output the port services from port scanner result

## OS Fingerprint

Purpose: Built off of service fingerprint to include OS

## Mini Scanner

Purpose: Automate the scanning process by a wrapper
